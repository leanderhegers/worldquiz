# data/emblems/

Original-Wappen und Emblems der Flaggen für "Spaß mit Flaggen" (spass-flaggen.html). 81 Dateien, je eine SVG pro Land/Gebiet (Kürzel = ISO 3166-1 alpha-2), dazu index.json (Namen de/en, Seitenverhältnis `ea`, Lage in der 4:3-Flagge `bb`).

Quelle: flag-icons 7.2.3 (MIT-Lizenz, https://github.com/lipis/flag-icons), Datei flags/4x3/<kürzel>.svg. Die Emblems sind 1:1 die Vektoren der Flaggen, nicht nachgezeichnet.

Gewinnung: Jede Flagge wird in Chrome gerendert; alle Zeichenelemente, die mindestens 25 % der Fläche oder 90 % der Breite/Höhe füllen (Streifen, Felder), werden entfernt, der Rest ist das Emblem. Das viewBox wird auf das Emblem zugeschnitten, danach svgo. Kanada (Ahornblatt steckt im selben Pfad wie die Balken) wurde einzeln herausgelöst. Nicht übernommen: reine Sterne, Halbmonde, Kreuze und Scheiben (gibt es als Grundformen) sowie Flaggen, bei denen sich das Emblem nicht sauber vom Hintergrund trennen ließ.
